# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-07

### Added
- Initial release of FastTranslate AI
- Hebrew-English bidirectional translation
- OCR support for text recognition from images
- Screenshot capture with Alt+S shortcut
- Clipboard translation with Alt+T shortcut
- Auto-detection of text language
- Keyboard layout conversion (Hebrew/English)
- Image overlay translation view
- Text view for translated content
- Copy to clipboard functionality
