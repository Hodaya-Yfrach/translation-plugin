# פרסום גרסה חדשה

התוכנות המותקנות מתעדכנות מאתר אמרי קודש:
`https://downloads.imreykodesh.com/downloads/fasttranslate/latest.yml` (ה-R2 של האתר).

## הכנה חד-פעמית במחשב שמפרסם

```
npm install -g wrangler
wrangler login
```

(אותו חשבון Cloudflare שבו גבי מפרסם את המתקינים שלו.)

## פרסום

מתיקיית הפרויקט:

```
npm run release:win
```

עם "מה חדש" (מוצג למשתמשים כשהעדכון מוכן) או קפיצת גרסה גדולה יותר:

```
npm run release:win -- -Notes "תיקון בתרגום תמונות|כפתור חדש" -Bump minor
```

הסקריפט (`scripts/publish-update.ps1`) מעלה את מספר הגרסה, בונה את המתקין, מעלה ל-R2 את המתקין,
את ה-blockmap ואת `latest.yml` (אחרון), בודק שהאתר מגיש את הגרסה, ודוחף ל-GitHub commit ו-tag של הגרסה.

## מה קורה אצל המשתמש

1. 15 שניות אחרי שהתוכנה עולה, ואחר כך כל 6 שעות, היא בודקת אם יש גרסה חדשה.
2. אם יש, היא מורידה אותה ברקע ומאמתת את הקובץ (SHA-512 מתוך `latest.yml`).
3. בשורת המצב, בחלון האודות ובתפריט המגש מופיע "הפעלה מחדש ועדכון": ההתקנה שקטה, בלי חלונות, והתוכנה עולה מחדש.
4. אם לא לוחצים, העדכון מותקן בשקט ביציאה הבאה מהתוכנה.

עדכונים פועלים רק בגרסה מותקנת (לא ב-`npm run dev`).
